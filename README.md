# PBADS - Personal Behavior Anomaly Detection System

## Project Overview
This is a complete microservices system for detecting anomalies in personal behavior.

## Services
- Auth Service: User authentication
- Data Service: Habits data management  
- Model Service: Machine learning
- Alert Service: Notifications

## How to Run
1. Clone the project
2. Run: docker-compose up -d
3. Open browser to http://localhost:8080
