🚀 PBADS - Complete Startup Guide

Personal Behavior Anomaly Detection System - Microservices Architecture

📋 Overview: This guide will help you start all components of the PBADS system, including databases, message brokers, microservices, and the frontend.

📦 Step 0: Prerequisites Verification

Run this PowerShell script to verify all required tools are installed:

Write-Host "=== PBADS PREREQUISITES VERIFICATION ===" -ForegroundColor Cyan

# Test all commands
Write-Host "`n1. Testing commands..." -ForegroundColor Yellow

# Java
Write-Host "Java: " -NoNewline
java --version 2>&1 | Select-String -Pattern "version" | ForEach-Object { Write-Host "$_" -ForegroundColor Green }

# Maven
Write-Host "Maven: " -NoNewline
mvn --version 2>&1 | Select-String -Pattern "Apache Maven" | ForEach-Object { Write-Host "$_" -ForegroundColor Green }

node --version | ForEach-Object { Write-Host "$_" -ForegroundColor Green }

Write-Host "PostgreSQL CLI: " -NoNewline
& "C:\Program Files\PostgreSQL\14\bin\psql.exe" --version 2>&1 | ForEach-Object { Write-Host "$_" -ForegroundColor Green }

# Python (if needed for ML components)
Write-Host "Python: " -NoNewline
python --version 2>&1 | ForEach-Object { Write-Host "$_" -ForegroundColor Green }

# Check services
Write-Host "`n2. Checking services..." -ForegroundColor Yellow

# PostgreSQL service
$postgresService = Get-Service -Name "postgresql-x64-14" -ErrorAction SilentlyContinue
if ($postgresService) {
    if ($postgresService.Status -eq 'Running') {
        Write-Host "PostgreSQL service: RUNNING" -ForegroundColor Green

        Write-Host "PostgreSQL service: $($postgresService.Status)" -ForegroundColor Yellow
    }
} else {
    Write-Host "PostgreSQL service: NOT FOUND" -ForegroundColor Red

Write-Host "`n=== VERIFICATION COMPLETE ===" -ForegroundColor Cyan

🗄️ Step 1: Database Setup (PostgreSQL)

1 Start PostgreSQL Service

Ensure PostgreSQL service is running:

# Check if PostgreSQL is running
Get-Service -Name "postgresql-x64-14"

# If not running, start it:
Start-Service -Name "postgresql-x64-14"

2 Create Databases

Create all required databases for the microservices:

# Connect as postgres superuser
& "C:\Program Files\PostgreSQL\14\bin\psql.exe" -U postgres

# In psql, run these commands:
CREATE DATABASE pbads_auth;
CREATE DATABASE pbads_data;
CREATE DATABASE pbads_model;
CREATE DATABASE pbads_alert;
CREATE DATABASE pbads_monitoring;

# Create user and set password
CREATE USER pbads WITH PASSWORD 'pbads_password';
ALTER USER pbads WITH PASSWORD 'pbads_password';

# Grant privileges
GRANT ALL PRIVILEGES ON DATABASE pbads_auth TO pbads;
GRANT ALL PRIVILEGES ON DATABASE pbads_data TO pbads;
GRANT ALL PRIVILEGES ON DATABASE pbads_model TO pbads;
GRANT ALL PRIVILEGES ON DATABASE pbads_alert TO pbads;
GRANT ALL PRIVILEGES ON DATABASE pbads_monitoring TO pbads;

# Exit psql
\q

3 Verify Database Connection

Test connection to each database:

# Test pbads_auth
& "C:\Program Files\PostgreSQL\14\bin\psql.exe" -U pbads -d pbads_auth -h localhost -c "SELECT 'Connected to pbads_auth'"

# Test pbads_data
& "C:\Program Files\PostgreSQL\14\bin\psql.exe" -U pbads -d pbads_data -h localhost -c "SELECT 'Connected to pbads_data'"

# Test pbads_model
& "C:\Program Files\PostgreSQL\14\bin\psql.exe" -U pbads -d pbads_model -h localhost -c "SELECT 'Connected to pbads_model'"

# Test pbads_alert
& "C:\Program Files\PostgreSQL\14\bin\psql.exe" -U pbads -d pbads_alert -h localhost -c "SELECT 'Connected to pbads_alert'"

# Test pbads_monitoring
& "C:\Program Files\PostgreSQL\14\bin\psql.exe" -U pbads -d pbads_monitoring -h localhost -c "SELECT 'Connected to pbads_monitoring'"

📨 Step 2: Kafka Setup

1 Navigate to Kafka Directory

cd C:\kafka\kafka_2.13-4.1.1

2 Format Kafka Storage (First Time Only)

⚠️ Important: Only run this command the first time you set up Kafka, or if you want to reset Kafka storage. 
.\bin\windows\kafka-storage.bat format -t $(.\bin\windows\kafka-storage.bat random-uuid) -c .\config\kraft-server.properties

3 Start Kafka Server

Keep this terminal open - Kafka must stay running:

.\bin\windows\kafka-server-start.bat .\config\kraft-server.properties
✓ Success: You should see "Kafka Server started" messages. Keep this terminal running.

🔧 Step 3: Start Infrastructure Services

Start these services in order, waiting for each to fully start before moving to the next:

1 Terminal 1 - Eureka Server (Port 8761)

Service Discovery - Must start first!

cd pbads-microservices\service-discovery\eureka-server
mvn spring-boot:run
⏱️ Wait for: "Started EurekaServerApplication" message
🌐 Access: http://localhost:8761 (no login required after security fix)

2 Terminal 2 - Config Server (Port 8888)

Configuration Management - Start after Eureka

cd pbads-microservices\configuration\config-server
mvn spring-boot:run
⏱️ Wait: ~15 seconds after Eureka starts
⏱️ Wait for: "Started ConfigServerApplication" message

3 Terminal 3 - API Gateway (Port 8080)

API Gateway - Routes all requests

cd pbads-microservices\gateway\api-gateway
mvn spring-boot:run
⏱️ Wait: ~15 seconds after Config Server starts
⏱️ Wait for: "Started GatewayApplication" message
🌐 Access: http://localhost:8080

⚙️ Step 4: Start Core Services

These services can be started in parallel (each in a separate terminal):

1 Terminal 4 - Auth Service (Port 8081)

cd pbads-microservices\core-services\auth-service
mvn spring-boot:run
✓ Default User Created: Username: admin, Password: admin123

2 Terminal 5 - Data Service (Port 8082)

cd pbads-microservices\core-services\data-service
mvn spring-boot:run

3 Terminal 6 - Model Service (Port 8083)

cd pbads-microservices\core-services\model-service
mvn spring-boot:run

4 Terminal 7 - Inference Service (Port 8084)

cd pbads-microservices\core-services\inference-service
mvn spring-boot:run

5 Terminal 8 - Alert Service (Port 8085)

cd pbads-microservices\core-services\alert-service
mvn spring-boot:run

6 Terminal 9 - Monitoring Service (Port 8086)

🔍 Quick Troubleshooting

Common Issues

  • Port already in use: Stop the service using that port or change the port in application.yml
  • Eureka 401 errors: Security is now disabled - restart Eureka server
  • Database connection errors: Verify PostgreSQL is running and databases exist
  • Kafka connection errors: Ensure Kafka is running and formatted
  • Service not registering: Check Eureka dashboard at http://localhost:8761
  • Login fails: Default credentials are admin/admin123 - check auth service logs

📝 Service Startup Order Summary

  1. PostgreSQL - Database service
  2. Kafka - Message broker
  3. Eureka Server - Service discovery (Port 8761)
  4. Config Server - Configuration (Port 8888)
  5. API Gateway - Routing (Port 8080)
  6. Core Services - Can start in parallel:
    • Auth Service (8081)
    • Data Service (8082)

    • Inference Service (8084)
    • Alert Service (8085)
    • Monitoring Service (8086)
  7. Frontend - React app (Port 3000)
